# Rule: No AI-Positive or AI-Characteristic Icons

## Strict Prohibition of AI-Associated Icons and Emojis
It is strictly forbidden to use any AI-positive, AI-characteristic, or generative AI-associated icons, emojis, or symbols anywhere in the project (UI components, buttons, badges, notifications, labels, or documentation).

### Prohibited Icons and Emojis
- Hourglass emojis or icons (e.g. ⏳, ⌛) used as loading/pending/AI indicators.
- Sparkles, magic, or glow icons (e.g. ✨, 🪄, 🌟).
- Robot, brain, or neural network symbols (e.g. 🤖, 🧠, 💡).
- Any decorative emojis representing "smart", "magic", "AI generation", or "assistant" actions.

### Required Practice
- Use standard, minimalist, functional SVG icons (such as simple Tailwind/DaisyUI/Heroicons outlines).
- Use clear, professional, plain text labels (e.g., "Jelentkezve (Elbírálás alatt)" instead of "⏳ Jelentkezve").
- Maintain clean, professional enterprise UI design standards.
